## Frequently asked questions

**Do I have to install Python, CUDA or FFmpeg?**  
No. The **portable Gumroad edition** comes with the required included components. Download, extract and launch.

**Can I swap faces in OBS, Discord or video calls?**  
Yes. Start Virtual Camera output in LiveFacer and select the virtual camera in a compatible application. A supported virtual camera driver, such as OBS Virtual Camera, connects the output to the system.

**Will the software stop working if I cancel?**  
No. **Your downloaded version keeps working.** Your active subscription provides new versions and priority support.

**Does LiveFacer work without an NVIDIA GPU?**  
Yes. AMD, Intel and CPU-only launchers are included. NVIDIA RTX is recommended for live performance.

**Can I swap several faces in one video?**  
Yes. Use **Many Faces** or **Map Faces** to select different source faces for different people.

**Can I run LiveFacer from an external drive?**  
Yes. The bundled Windows edition is portable and can run from a folder or external drive.
